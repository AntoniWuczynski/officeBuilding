# DESIGN.md — Office Building
Date: 2026-09-29   Status: diverged
Codified from: new (the previous scaffold's dark oklch theme was an agent default, never an owner decision, and is replaced)
Identity: The only agent manager where your coding agents work in a cutaway office building you can see into, and every manager's panel is an object on the floor.
Volume default: canvas-first. The building and floor scenes are the content and carry the identity. Chrome around them (directory bar, rail, sidebar, terminal) is quiet signage: paper plates, ink borders, no shadows.
Tokens:
  --sky-top: #CFE3EE; --sky-bottom: #EEF4F1 (the one gradient: the sky behind the scene)
  --plaster: #F1ECE2; --plaster-shade: #E2DACB (walls)
  --boards: #D9BD93 (floors); --concrete: #BDB6A8; --concrete-shade: #A39C8E (slabs)
  --timber: #9B7753; --timber-front: #7A5A3C; --timber-side: #634831 (desks)
  --glass: rgba(200,228,240,.36) (manager's office)
  --ink: #1C1F24 (text, sign borders); --paper: #FFFDF8 (signs, panels); --rule: #CFC7B6
  --signage: #B5532B (enamel sign red: roof sign, primary action only)
  Status, semantic only: --ok #2FBF71 (healthy), --wait #F2B33D (needs you), --fault #E5484D (error), --off #7C8088 (empty or finished)
  Props (objects in the room, never chrome): --roof #8E887C, --window #AFD3E6, --monitor #2B2E33 / #40444C / #1F2226, --cork #C99A5B / #8C6436, --brass #C9A45C / #8A6D2E, desk plant (agent in a git worktree, A Human 2026-10-06) leaves #6F9A4E / #557A3A, soil #4A3626, pot #B8683F / #96512F, sticky notes #F7E27A / #9FD8F2 / #F6B5C8, manila folder (a finished subagent's work, A Human 2026-10-11) #E3C27A / #B08A3E, --terminal #16181C with #E8E6E1 text
  People: realistic cut-outs (A Human 2026-10-09): a fixed cast of seven characters drawn by Codex's image generation as front-facing parts sheets (art/cast/raw), cut by art/cast/cut.py into src/assets/cast. Each agent id picks one of six workers (src/lib/looks.ts); the manager is always the seventh. Realistic pictures, cartoon motion.
  Pets (A Human 2026-10-09): what an agent leaves running stands in front of its desk, cut out the same way. A shell is a seashell, Claude Code's Monitor tool an owl, a browser it drives a cat, any other program a dog.
Type:
  Signage: "DIN Condensed" (macOS system font, bold), uppercase allowed only on physical signs (roof sign, floor nameplates). Fallback "Arial Narrow", sans-serif.
  Numerals: "DIN Alternate" bold for counts and floor numbers (tabular). Fallback the mono stack.
  Interface text: the macOS system face (-apple-system). Recorded decision: it is a native desktop app and the chrome speaks the platform's voice.
  Code, paths, terminal: "SF Mono", Menlo, monospace.
Motion:
  Characters: South Park-style cut-out animation (A Human 2026-10-09): flat pieces hinged at shoulder, elbow, neck and hips that snap between keyframes (steps), quick and exaggerated, never smooth. The loops encode session state: typing in bursts with forearms striking the keyboard, hand on chin when thinking, arm up and waving when it needs you, sitting back and looking round when idle, slumped when finished. Upper arms tuck behind the torso and forearms sit in front of it. A stuck agent (error) lies flat on the floor in front of the desk, eyes shut, with a blinking red "!" (owner request, 2026-09-29). Semantic, not decorative.
  Pets pop in with an overshoot when their program starts and pop out when it ends.
  Navigation: one camera move per action (dive into a floor, pull back to the building), 450-600ms tween, ease-out, no bounce, no overshoot.
  Agent-to-agent messages: a worker walks a note to the recipient's desk.
  prefers-reduced-motion: character loops stop, camera moves become cuts, walkers teleport.
Signature device: the metaphor made structural. Every sidebar section is an object in the room and opens its panel: memo pile on the manager's desk = Decisions queue, cork board = Human TODO, whiteboard = AI TODO, meter on the wall = Spend, brass plaque = Info, clipboard sign-out sheet by the door = Signed out (sessions to resume, A Human 2026-10-01), "Your terminal" over the manager's office = Shells (the human's own plain shells, Cmd+N, A Human 2026-10-11), an agent walking a note to a colleague = agent-to-agent message, a finishing subagent walking a manila folder to its agent = its work handed in (A Human 2026-10-11), the manager at the desk in the manager's office, or the "Hire a manager" tag on that desk while nobody is hired = Manager (the floor's manager agent, its waiting notes and its log, a call the build made on 2026-11-12), fuse box beside the toolbox in the plant room = Settings (app-wide, also Cmd+,, A Human 2026-11-12). The fuse box is drawn in the plant room's grey metal (the --duct tokens), with no new colour. Settings is the one panel that is a dialog plate and not a sidebar section, because it also opens from the building view, which has no sidebar. It never shares the screen with another plate or the docked terminal: opening one closes the other.
Menus: a right-click on a worker, and a click or right-click on a helper working in a git worktree, opens a small "Open in…" menu that lists the installed editors (a call the build made on 2026-11-12, not yet seen by A Human). It is a paper plate with an ink border and no shadow, drawn flat above the scene like the worker's hover card, so the walls cannot slice it. It closes on a press outside it, on Escape, when the window loses focus and when the floor is zoomed. It is a menu and not a panel, so the hard no on a panel overlapping a panel does not cover it. The "Open in" button with its arrow is chrome on a panel's header, the sign-out sheet and the Info panel, and adds no object to the room.
Board items: every item on the cork board and the whiteboard that comes from somewhere carries a small text badge saying where (calls the build made on 2026-11-12, not yet seen by A Human). A file item shows its file's name, an item from Linear shows "Linear · ENG-123", and an item from the app's own records shows nothing. The badge is mono type on paper with an ink border, with no logo and no emoji. A Linear badge is a button that opens the issue in the browser. An action that changes something outside the app asks first in a row inside the list ("Mark ENG-123 as Done in Linear?"), never in a dialog, because a panel must not overlap a panel. Each board that shows Linear items has one status line with a Re-check button. The link between a floor and Linear is a row on the brass plaque's Info panel, and the key is a group in Settings. Connectors add no object to the room.
QA desk: a floor whose quality assurance (QA) is switched on has one more desk, in its front-left corner, with a magnifying glass on it (calls the build made on 2026-11-12, not yet seen by A Human). The glass is drawn in CSS from tokens already listed, an --ink ring with a --window fill and a --timber-front handle, with no image and no new colour. The reviewer sits at this desk while it works and is drawn like every other worker. The room grows a little deeper, unless it is at its minimum depth, so the last row of desks keeps clear of the corner. The desk's tag reads "QA" and opens the brass plaque's Info panel, where the "Quality assurance" row holds the switch, the status, the last reviews and Check now. The result is a drawn rubber stamp on that tag and on the floor's nameplate in the building view. It reads "QA passed" in --ok or "QA notes" in --wait, in signage type, uppercase because a stamp is a physical mark, with a border in its own colour, tilted 6 degrees, with no fill and no shadow. The words differ as well as the colour, so it does not rely on colour alone. It is never an emoji. Switching QA on leads to posts on GitHub, so it asks first in a row inside the Info panel, never in a dialog. The settings are a group in Settings.
Manager: the cut-out in the manager's office is the floor's manager, an agent that hands work to the desks (calls the build made on 2026-11-12, not yet seen by A Human). It adds one object to the room, the manager at its desk, which opens a Manager section in the sidebar. With nobody hired the chair is empty and the desk carries a small paper tag reading "Hire a manager", drawn like the tags on the other room objects. On the Setup floor the chair is empty and there is no tag. Once hired, the seventh cast character sits there in the pose of its session's state and is a button. The lamp on its desk uses the status tokens and no new colour: --ok while it works, --wait while a call it escalated is open, --off while it is paused. The manager walks its own notes out from its office, as workers do, and its chair is empty while it walks. A desk the manager drives carries the word "managed" under its name tag, in mono type on paper with an ink border, like a board item's badge. A desk with notes waiting carries a sticky note in the existing sticky-note yellow with an ink border, tilted 4 degrees, showing how many wait. The worker's label and hover card also say in words that the desk is managed and why a note waits. The Manager panel is a sidebar section and not a dialog. Its switches (Paused, "May hire desks") act at once, and it has no confirmation row. Text that comes from the manager is shown as plain text only, never as Markdown or links. The panel has no button that ends the manager, because the building never stops an agent, and it says to type /exit in the manager's terminal. The settings are a group in Settings.
Chat: a desk's docked panel has two faces, terminal and chat, in the same dark palette, --terminal with its text colour (calls the build made on 2026-11-12, not yet seen by A Human). It is still the one docked panel, so the chat adds no object to the room and no new panel type. A chat opens at 60% of the floor's height and stays resizable, and it remembers its own height apart from the terminal's. A desk that keeps a terminal has a two-button switch in the panel's head, Chat and Terminal, drawn like the "Open in" button, and the pressed one is inverted. An agent's message is Markdown with raw HTML off. A link or an image is never an element. It is drawn as text with its address, so nothing in a chat can be clicked or loaded. A tool call is a card that folds, and its command, output and diffs are plain mono text. A diff uses the status tokens for its lines, --ok for added and --fault for removed, with a + or - in front, so it does not rely on colour alone. Thinking and long text are folded, long text behind a "Show all" button. A permission prompt on a terminal desk is a card with one button, "Answer in the terminal", and the chat never answers for A Human. A waiting message sits above the message box with the reason it waits and a Withdraw button. No new tokens, no emoji and no internal names in the interface.
Routing: provider routing adds no object to the room (calls the build made on 2026-11-12, not yet seen by A Human). It is a group in Settings and an "Account context" row on the brass plaque's Info panel. Inside the group each account context and each connection is a card, paper with a 1px ink border and no shadow, and a connection's card folds. A card is part of the Settings plate and not a panel of its own. Removing a context or a connection asks in a row inside its card, never in a dialog. A connection's kind is shown by its name ("Claude subscription", "Anthropic API key"), never by its internal name. A routed desk shows its route as a strip inside its docked panel, between the panel's head and the terminal or chat, in the panel's dark palette (a call the build made on 2026-11-13, not yet seen by A Human). The strip is part of the one docked panel and not a panel of its own. It pushes the terminal down and covers nothing. It carries an 8px square lamp in the status tokens, --ok while a connection serves the desk, --wait before the first request and while the active connection has a problem, and --fault while the desk is blocked, and the state is always written beside it in words ("Route: Blocked"), so it does not rely on colour alone. A Details button unfolds the desk's order inside the panel, up to 45% of its height, with a Retry and a "Switch to this" button drawn like the dark "Open in" button. A blocked route is a plain sentence and never a spinner. No new tokens.
First-paint emotion: command-play (a management sim: you are in charge, and it is a toy you want to poke). Owner picked "Command and Play"; recorded as one compound.
Voice: matter-of-fact British English. States in human words: Working, Thinking, Needs you, Stuck, Idle, Finished. Errors say what happened and what to do next. No em dashes in interface copy.
Dark mode: deferred (daylight only)
Hard-no exceptions: none
Rejected directions: not chosen on 2026-09-29 (drafts page): B night tower, C architect's axonometric, signature 1 lift ride, signature 3 16-colour pixel constraint. Owner may revisit; agents do not re-propose them.
Implementation constraints:
  CSS 3D rig. Building: rotateX(68deg) rotateZ(18deg), shallow storeys (depth 80, height 56) with desks near the front so the slab above never hides a worker. Single floor: rotateX(60deg) rotateZ(45deg), no ceiling.
  Billboards (people, bubbles, nameplates) counter-rotate with rotateZ(-z) rotateX(-x) so they always face the camera.
  Tauri renders in WKWebView: every scene change must be checked in WebKit, not only Chromium.
  Minimum window 900x600 (tauri.conf.json). That is the small-viewport floor. The 320px web floor does not apply to this desktop app.
Hard nos (project-local additions): emoji as icons; internal enum names in the interface (waiting-human, raise-window); a panel overlapping another panel; search that removes storeys from the building (non-matching floors dim instead).
